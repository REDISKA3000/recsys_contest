# recsys_contest
recsys_contest
Финальное решение построено как ансамбль трёх моделей BERT4Rec из библиотеки RePlay. Все модели обучаются на последовательностях фильмов пользователя.
Последовательности формируются из взаимодействий, отсортированных по `timestamp`; максимальная длина истории — 100 фильмов. Для BERT4Rec с рейтингами оценка добавляется как отдельный categorical-признак последовательности. Для всех моделей исключаются фильмы, уже присутствующие в истории пользователя.

Модели обучаются предсказывать следующий фильм по истории пользователя. 

В ансамбль входят:

- базовая BERT4Rec: `hidden_size=128`, `block_count=2`, 500 эпох;
- BERT4Rec с дополнительным последовательным признаком оценки фильма `rating_seq`;
- увеличенная BERT4Rec: `hidden_size=256`, `block_count=3`, 300 эпох.

Для каждой модели сохраняются top-100 рекомендаций, после чего они объединяются RRF: итоговый score фильма равен сумме `weight / (60 + rank)` по всем моделям. В финальный submission попадают 10 фильмов с максимальным итоговым score.
- base BERT4Rec — вес `0.60`;
- BERT4Rec с рейтингами — вес `0.25`;
- large BERT4Rec — вес `0.15`.
Итоговый сабмит: `submission_bert4rec_three_models.csv`.  
Лучший public результат: `Recall@10 = 0.2721`.
